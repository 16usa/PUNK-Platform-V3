# PUNK Platform V3 — Replit demo

## Current Replit workspace

This archive is preserved under `imported/` in the PUNK Platform V3 artifact. The workspace Run workflow starts the included Express server with Replit's assigned `PORT`; `server.js` binds to `0.0.0.0`. To run this archive outside the workspace, install its dependencies and run `npm start` from this directory.

## Run
Import this ZIP into a new Replit Node.js project. Run `npm install` and `npm start`. Preview opens on port 3000 or the Replit-assigned `PORT`.

## What is included
- Responsive interactive PUNK UI: Home, Trending, New, Create Token, Token/Buy/Sell, Creator Profile, Portfolio, Transactions, Settings.
- Two demo X/X Money connection modals and a demo creation confirmation.
- Sample token cards, prices, market caps, chart data and demo-only transactions.
- The October 7 original reference at `/original-reference.png`, and twelve **unaltered crops** at `/reference/panel-01.png` through `/reference/panel-12.png`. Access the reference gallery from the footer.

## Fidelity / limits
The original image panels are exact crops of the supplied reference. The interactive HTML/CSS screens are an implementation inspired by it, **not a guaranteed pixel-perfect recreation**. The reference depicts conceptual X Money features; no real X Money, Solana mint, wallet connection or trades exist. All data are demonstrative and not live.

No secrets, wallet seed phrases, or funds are required.
